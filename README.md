## Featured Projects

**AI & Agents**
- 📞 [**Hinglish Caller Bench**](https://github.com/payalkanyan/hinglish-caller-bench): open-source harness that stress-tests AI customer-service agents with simulated Indian callers (English, Hindi, romanised Hindi, Hinglish, mid-call switching). Grades task completion, tool correctness and language fit separately, with confidence intervals and pass^k.
- 🧠 [**Personal Knowledge OS**](https://github.com/payalkanyan/Personal-KnowOS): agentic RAG assistant with autonomous tool routing, hybrid retrieval (RRF + cross-encoder) under 200 ms, async ingestion (Celery, Redis, PostgreSQL) and a Chrome extension.
- 🤖 [**Kora**](https://github.com/payalkanyan/readthedocs): RAG assistant for AWS S3 documentation (Ollama + ChromaDB + FastAPI, Dockerized) · [Live demo](http://awsrag.duckdns.org)
- 🔍 [**HiLabs Roster Parser**](https://github.com/payalkanyan/parser): hybrid OCR + rule-based + NER pipeline that extracts provider data from healthcare emails, with confidence scoring and audit logging · **HiLabs AiQuest '25 winner**

**Machine Learning**
- 💳 [**Credit Card Default Prediction**](https://github.com/payalkanyan/CreditCardBehPred): behaviour-score model for 30K+ cardholders; LR, RF, XGBoost, LightGBM and ensembles with SMOTE (AUC 0.78), plus cost-aware threshold tuning
- 📚 [**ScholarLens**](https://github.com/payalkanyan/scholar_lens): arXiv paper recommender using TF-IDF and cosine similarity, with a Streamlit UI (82% top-5 precision)

**Systems**
- ⛓️ [**goevm**](https://github.com/payalkanyan/goevm): Ethereum Virtual Machine (EVM) implementation in Go
